# MediaFlow v295 — Responsive Navigation Repair & Fresh-Account Category Defaults

MediaFlow v295 is built directly from the accepted v294 baseline.

## Highlights
- Repairs the intermediate/tablet-width bottom navigation so tabs no longer cram into the bar and the More menu stays inside the viewport.
- Replaces the fresh-account default category set with the complete 22-category MediaFlow collection using packaged built-in category artwork.
- Preserves existing account category data; the new set is the default for fresh/reset category state only.
- Audits Cloud Sync / Sync Now, Full + Automatic Backup, Full Data import/export, Settings Presets, XP, History exports, Personal Order import/export, Collections import/export, automatic updates and PWA release metadata.
- PWA app shell is regenerated for v295 and includes every packaged category icon.

## Persistent schema compatibility
- Cloud Sync: v201
- Full Backup Schema: v29
- Settings Preset Schema: v1
- Personal Order Export: v5
- Collections Export: v2
