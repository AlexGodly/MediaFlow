## MediaFlow v557 Stable

### Add to Logging
- "Add to Logging" (in the + menu) now opens only **Browse Library**: search, filters, sorting, Select Visible / Add Selected and per-title Add — nothing else.
- Titles go straight into your current Logging draft; the popup header shows how many titles are added, and it updates as you add.
- Quantities, XP, notes and saving stay in the full Logging workspace on the Dashboard. **Open Logging** in the popup takes you there with the same titles.
- Closing the popup keeps everything you added. Works on any page, on desktop and phone.
