# MediaFlow v265 — UX Stability, Dynamic Settings & Collapsible Navigation

- Delete Title is available from Edit Title and Title Details with a designed confirmation dialog.
- Library search keeps keyboard focus and caret through debounced result refreshes.
- Normal Library no longer flashes its hidden legacy category dropdown after category changes.
- Normal Library status chips use the same semantic status icons as Dynamic Library.
- Personal Order category filtering is viewport-clamped and no longer clipped on the left or right.
- Today’s Balance is rebuilt as a non-interactive, organized Dashboard insight with cleaner typography and no unnecessary action arrows.
- Settings updates morph in place instead of rebuilding the Settings page, eliminating the visible refresh/jump cycle for normal preference changes.
- The desktop app navigation gains a persistent theme-aware collapsed/expanded state.
- All v264 data/persistence compatibility remains unchanged.
- PWA cache advances to `mediaflow-pwa-v265-shell-v1`.
