## 1. Logging XP Summary — professional responsive redesign

### Previous problem
The Logging XP preview appeared as a large, pale inline message with minimal visual hierarchy, for example `+75 XP for this log` followed by a plain-text base/rotation/streak formula. Its appearance was out of place in both Logging interfaces.

### v382 change
- Replace the legacy `#xp-preview` contents with a themed, compact XP summary card in **Quick Logging and Per Unit**.
- Distinguish **Estimated Reward** and a large, readable `+XP` value.
- Show four clearly labeled values: **Base XP**, **Rotation multiplier**, **Streak multiplier**, and **Streak days**.
- Preserve the rotation category/status description and explicitly note that XP is granted **when the log is submitted**.
- Use existing theme CSS variables, muted accent treatment, responsive sizing, clear spacing, tabular numbers, accessible labels, and reduced-motion support.
- Replace the previous inline background and border styling rather than simply adding another card inside the old pale block.
- Update the card through the existing `refreshXPPreview()` path as amount, time or Per Unit draft changes modify the estimate.

**XP integrity:** This is presentation-only. v382 does **not** change actual XP formulae, rotations, streaks, session submission, History, or cloud persistence.

## 2. Recommended Title — direct addition in both Logging interfaces

### Previous problem
`Use recommended title` previously called `App.selectLogTitle(...)`, populating the Library search input without adding the title to `S.logDraft.entries`. This caused Per Unit to appear non-functional, and Quick Logging required an extra manual Add step.

### v382 change
- The recommended-title shortcut calls the existing canonical `App.v378QuickAdd(...)`, which supports **Quick Logging and Per Unit**.
- Clicking once adds the **actual recommended Library title** to the current session draft, with the correct `libraryId` and title metadata.
- The active Logging interface is preserved; the app does not switch modes.
- The Added Titles list becomes visible if it was hidden.
- Clicking again when already added **does not duplicate the entry**; it expands/focuses the existing card instead.
- Existing drafts, staged units, entry quantities, custom ordering and unsaved data remain untouched.
- Title addition does not award XP or alter Library progress. Logging still requires normal submission.
- A clear success toast is emitted only when the direct add succeeds.

### Semantic success feedback
- **Before adding:** a single plus icon and **Use recommended title**.
- **After actual addition:** a single check-circle icon and **Recommended title added**.
- The success state is derived from the **actual draft membership**, not the now-cleared search field.
- An already-added title can be located with the same button, instead of being blocked in a misleading selected state.
- Native inline SVG protects the intended icon from the legacy generic circle-arrow fallback.

## 3. Per Unit — two real progress bars on every added title

Each Per Unit added-title card now includes a compact **Progress outlook** section directly under the title's existing metadata, while preserving artwork, status, category, priority, unit counts, action buttons and episode editing.

| Display | Meaning |
|---|---|
| **Current progress** | Current saved Library progress before this draft |
| **After this draft** | Expected Library progress **if** the current draft is submitted |
| **Drafted units** | Number of staged episode/chapter/issue/etc. entries |

### Progress calculation
- Uses the existing `v369ProjectedTitleProgress(...)` function, the canonical method used by Per Unit logging.
- Only *contiguous new* episode/unit numbers advance projected progress. Gaps and repeated units do **not** fabricate higher progress.
- Honors title/season totals and the existing season aggregation model.
- Clamps visual projections to a known total.
- Unknown totals display a clear `?` and an unknown-state track instead of inventing a completion percentage.
- Refreshes when draft units are added, removed, repeated, renumbered or reassigned to a season, because the section is generated by the existing panel renderer and `v369RefreshPanels()`.
- Uses distinct, theme-aware current and projected fills, screen-reader labels, and responsive one-column layout at narrow widths.

**Scope:** Per Unit's **added title cards** only. This update does not introduce progress bars in Quick Logging, the main Library, or unrelated cards.
