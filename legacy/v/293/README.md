# MediaFlow v293 — Cinematic Recommended Cover Background Overhaul

**App release:** v293  
**Base:** MediaFlow v292 Modular

## v293

- Reworked the optional **Recommended title cover as background** Dashboard mode so the artwork is intentionally visible and cinematic instead of faint/underwhelming.
- Added a stronger full-bleed color/art layer, a sharper cropped artwork layer, lighter readability scrims, theme-aware glass recommendation surfaces, richer cover depth, and improved title/control contrast.
- The left information zone remains protected for readability while the center/right side keeps significantly more of the recommended artwork visible.
- Tablet and mobile retain visible artwork with dedicated responsive scrims rather than simply hiding the background effect.
- The v292 setting, default behavior, persistence, Cloud Sync, Full Backup, Settings Preset compatibility, missing-cover fallback, recommendation logic, and logging logic remain unchanged.
- PWA shell advanced to `mediaflow-pwa-v293-shell-v1`.
