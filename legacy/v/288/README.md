# MediaFlow v288 — Personal Order Queue Views & Collection Drill-down

**App release:** v288  
**Cloud Sync:** v201  
**Full Backup:** Schema v29  
**Settings Preset:** v1  
**Personal Order Export:** v5  
**Collections Export:** v2

## v288

- Collection Queues now sit below Category/title queues by default.
- Queue Display controls can switch which section appears first and independently show/hide Category/title queues or Collection Queues.
- Assigned Collections can optionally be mirrored inside normal By Category queues with the same rules and controls.
- Every assigned Collection has a semantic Open button that opens the real Collection page.
- Assigned Collections can expand to show their live ordered titles with covers, category/status/progress and eligibility state.
- Expanded Collection title lists are paginated at 10 titles/page by default; the page size is typed and adjustable from 1–1000.
- Direct titles shown around Collection blocks in the Collection Queue now have covers too.
- Queue display preferences persist through normal Personal Order state/cloud/Full Backup behavior.
- Personal Order Export remains v5 and includes the queue-view preference extension without a migration requirement.
- PWA shell advanced to `mediaflow-pwa-v288-shell-v1`.
- No data migration required.
