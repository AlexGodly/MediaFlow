# MediaFlow v255 — Cover Status Color Polish

MediaFlow v255 is a small visual polish release for the **On cover** status overlay introduced in v254.

## Main changes
- Changed the **Completed** status icon color on covers to **blue**.
- Changed the **Plan to Watch** status icon color on covers to **white**.
- Applies consistently in both **Normal Library** and **Dynamic Library**.
- Applies only in the cover-overlay status badge used by **Covers** and **Covers+Titles**.
- Other status colors and all non-cover Library views remain unchanged.

## Preserved behavior
- v254 Status / Category / Rating / Progress cover-overlay toggles.
- v253 History batch management and recommended-title logging shortcut.
- v252 Seasons View and season-aware logging/import/persistence.
- v250 cloud/persistence reliability.
- Application update and PWA separation/diagnostics.
- Cloud Sync v201, Full Backup Schema v29, Settings Preset Schema v1, Personal Order Export v4.
