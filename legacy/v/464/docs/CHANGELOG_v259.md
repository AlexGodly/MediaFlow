# MediaFlow v259 — Compact Category Icon Showcase

MediaFlow v259 is a focused visual cleanup for the built-in category artwork picker introduced in v258.

## Built-In Category Icon Grid

- Removed the visible category names beneath the packaged MediaFlow artwork.
- Removed the extra neutral action/arrow icon that was being injected above each built-in artwork tile.
- Reduced the size of the built-in artwork tiles and image previews for a cleaner, denser icon showcase.
- Kept each icon's name available through hover tooltip and accessible `aria-label` text.
- Preserved selection highlighting and the existing v258 packaged-icon behavior.
- Preserved all 22 built-in category artwork assets.
- Preserved Emoji & symbols, custom icons, URL icons, category colors, cloud persistence, backups, imports/exports, and PWA offline caching.

## Compatibility

- Cloud Sync: v201
- Full Backup Schema: v29
- Settings Preset Schema: v1
- Personal Order Export: v4
