# MediaFlow v295

## Added
- Logging Intensity dashboard slider placed above the logging hero on Dashboard.
- Five default anime-inspired intensity modes with editable names, icons, and XP multipliers.
- Restriction system for title rerolls, category rerolls ("Give me something else"), skip, and recommended-title-only logging.
- Persistent high-commitment sessions for mode 3 and above: ending a session keeps the current task so the next session resumes where it stopped.
- Large built-in background preset library for the intensity card with automatic, random, manual-preset, and custom-URL modes.
- Organized Settings section for Logging Intensity with mode customization and background controls.

## Changed
- Consumption XP now also respects the selected Logging Intensity mode multiplier.
- Dashboard buttons visually disable themselves when blocked by the active intensity mode.
- Exact-title locked mode now locks the log form to the recommended title when exact title recommendations are enabled.

## Notes
- Built-in background presets are generated as lightweight decorative anime-scene tones, so the card stays theme-aware and readable without needing dozens of external files.
