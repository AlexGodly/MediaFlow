## MediaFlow v577 Stable

### Titles logged by parts
Edit title → **How this title is logged**: *Normal* (as before; seasons fill in order) or *By parts*.
- A part can be anything: a game mode, a chapter, an arc. Each has its own kind ("Mode"), name, counter, and optionally its own unit and time per unit (empty: the title's own, then the category's).
- The title's number is the sum of its parts. A part with a total can be completed (✓); a by-parts title is completed only by hand.
- **Logging:** after adding the title, chips pick the parts; each chosen part gets its own line and bar — e.g. *Competitive · Match 41 → 44 (+3)* in Progress reached, or an amount in Amount consumed. Several parts can be logged at once.
- **Advanced logging:** each unit is tagged with a part (the season picker) and takes that part's time.
- **Batch Log:** the same part chips in each row.
- Minutes, XP and the category amount use each part's own time. History shows which parts moved.
- Normal titles with seasons log exactly as before.

### XP History adds up
Adding a title and completing one earn XP that XP History never listed. Every title now has its "Library · added title" row (on the day it was added) and "Title completed" row, plus the completion streak bonus, so the list sums to your total XP.

### Every keyless source, connected
Checked live against the real services:
- **New cover sources:** Wikidata images (from Wikimedia Commons), Wikimedia Commons, Library of Congress, Inventaire.io, EpisoDate.
- **New details sources:** Wikidata, Library of Congress, Crossref, Inventaire.io, EpisoDate (now directly, no key), German National Library, BnF.
- Each is in Sources, in category presets and has a connection test. Deezer and the Grand Comics Database need no key but don't let a web page read them, so the MediaFlow app uses them. BoardGameGeek (now needs a key), MangaUpdates and Royal Road (block automated requests) and GOG (search no longer answers) show why they can't be used.

### Batch Log draft on every device
An unfinished Batch Log — rows, amounts, minutes, parts, date, time and note — is saved to your account and continues on any device; an open Batch Log follows changes from another device within seconds. The app's multi-title "Log any title" uses the same draft.
