# MediaFlow v231 — Modular Project

**App release:** v231  
**Stable feature base:** v201  
**Cloud Sync:** v201  
**Full Backup Schema:** v29  
**Settings Preset Schema:** v1

MediaFlow v231 improves Settings navigation and expands the v230 Choice & Filter Layout inheritance model while keeping all existing data schemas compatible.

## Main v231 changes

- Added **Library Mode** to the Settings sidebar and Library group with a dedicated semantic icon.
- Added active/current-section highlighting to the Settings sidebar while scrolling or jumping between sections.
- Removed the repeated “Drag with ☰…” helper sentence from custom popup/filter ordering cards.
- Changed default **Set Priority** order to **High → Medium → Low**.
- Added **Follow Dynamic Status Order** to Set Status.
- Added **Follow Set Category** to Category Filter.
- Added **Follow Dynamic Status Order** alongside **Follow Set Status** for Status Filter.
- Preserved custom orders when inheritance modes are selected.
- Existing Cloud Sync v201, Full Backup Schema v29, and Settings Preset Schema v1 remain unchanged.

See `docs/CHANGELOG_v231.md` for full release notes.
